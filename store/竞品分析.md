## 二、他们有、我们没有的功能

按「值不值得做」排序。

### ⭐ 值得做

**1. PIN 模式（4–8 位数字）**
- 谁有：Chrome Profile Lock (Secure)，也就是**用户最多的那个**
- 为什么重要：这个品类的核心摩擦是**一天要输几十次密码**。5 分钟自动锁的场景下，
  敲一串长密码是真的烦。PIN 是这个痛点的直接解法
- 我们的实现成本：低。复用现有 PBKDF2 路径，只是加一个数字输入模式和不同的长度下限
- ⚠️ 注意：PIN 熵低得多，暴力破解防护必须更硬。我们已有指数退避，可能要加长冷却

**2. 密码找回机制**
- 谁有：Chrome Profile Lock（recovery code）、Chrome Profile Lock Secure（安全问题）
- 我们现在的答案是「去 chrome://extensions 卸载重装」，**设置全丢**。这是个真实的恐惧点
- 实现：设置密码时生成一次性恢复码，显示一次，存哈希。低成本，去掉一个心理门槛

### 🤔 可以考虑

**3. 允许域名白名单（锁定时仍可访问的站点）**
- 谁有：Chrome Profile Lock
- 注意这跟我们的 protected sites 是**反过来的**：我们是「这些站要额外验证」，
  它是「锁着的时候这些站还能用」。适合放着音乐、计时器、监控面板的场景

**4. 标签页保存与恢复**
- 谁有：Chrome Profile Lock (Secure)、Chrome Profile Locker Ultimate
- 边际价值不高，Chrome 本身就会恢复会话

**5. 锁定时自动关闭新开的窗口/标签**
- 谁有：Chrome Profile Locker Ultimate
- 我们的 content script 会覆盖新窗口里加载的任何页面，strict mode 管住 chrome:// 页面。
  **需要实测确认有没有漏洞**，有漏洞才补

### ❌ 不该做（要有立场，不能照抄）

**6. 屏蔽 DevTools（F12 / Ctrl+Shift+I）+ 阻止扩展被卸载**
- 谁有：Chrome Profile Lock (Secure)、Chrome Profile Locker Ultimate
- **我们是故意不做的**，见 `NOTES-中文.md`：chrome://extensions 是留的逃生门
- 理由：①忘了密码就永久锁死自己；②**挡不住真想绕的人**，
  他可以换个操作系统用户、可以直接从磁盘读 profile 目录；
  ③ 我们的 `SECURITY.md` 威胁模型写得很清楚，防的是「顺手翻你电脑的人」，
  不是防取证级攻击者。装作能防后者是欺骗用户
- **抄了会让产品变差**，而且跟已公开的威胁模型自相矛盾

## 三、我们有、他们没有的（商店描述该往前放）

| 我们的 | 竞品情况 |
|---|---|
| **锁定状态不跨设备同步** | **没有任何一家提到这件事**。这是整个产品的立身之本 |
| **profile 级闲置判定**（不是系统 idle） | 没人区分。共用电脑上别人在用，系统永不 idle，他们的自动锁就永不触发 |
| **每台电脑独立的自动锁时长**（v0.5.0） | 没有 |
| 受保护网站（银行/邮箱二次验证） | Google Chrome Profile Lock **要收费**（Gumroad），我们免费 |
| 自动锁时长 1–480 分钟 | 那家**收费**版才给 1–60，我们免费给到 480 |
| 主题 | 那家**收费**，我们免费 |
| 失败尝试报告 | 那家**收费**（叫 security activity logs），我们免费 |
| 开源 + MIT + 零网络请求 | 只有我们 |
| 34 KB | 竞品 39–56 KB，最差的 1.49 MB |

**一句可以直接用在商店描述里的话**：
Google Chrome Profile Lock 拿去卖钱的四样东西（网站保护、自定义时长、主题、活动日志），
Nightlatch 全部免费，而且开源。
