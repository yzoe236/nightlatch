    Honest security notes (please read once)
    • This is a curtain against casual snooping, not a vault. Anyone who opens chrome://extensions and disables the extension gets past it — true of every product in this category. Real security on a shared machine is Win+L or separate OS accounts; this is a second curtain on top.
    • Lock state lives only in this computer's memory (chrome.storage.session): it never syncs, and a browser restart always returns to locked. Unlocking at home never unlocks the lab machine.
    • Only a salted hash of your password is stored (PBKDF2-HMAC-SHA256, 600k iterations). Settings sync with your account; each machine still locks and unlocks independently.
    • Forgot your password? Use the recovery code from the lock screen. If that is gone too, remove the extension at chrome://extensions and reinstall — we deliberately do not block that page, so you can never lock yourself out for good. Nothing readable is stored, only the hash.
